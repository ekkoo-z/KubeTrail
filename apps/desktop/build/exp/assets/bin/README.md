# Prebuilt EXP Binaries

Reviewed prebuilt helpers can be staged here by template and platform:

```text
exp/assets/bin/<template-or-poc-id>/<os>-<arch>/<binary>
exp/assets/bin/<template-or-poc-id>/<os>-<arch>/manifest.json
```

Every binary manifest should record source URL, commit or release tag, build command, sha256, expected arguments, and side effects.
